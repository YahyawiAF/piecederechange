# PiècesExpress TN (`pieceRechangeMotor`)

Expo (SDK 57) buyer app for spare parts in Tunisia. UI follows the PiècesExpress design (blue `#1565C0`, orange `#FF6D00`).

## Run

```bash
npm install
npm run web
```

Leave `EXPO_PUBLIC_ORG_ID` empty to use the local demo catalog (`src/data/seed.ts`).

## Screens

**Tabs:** Accueil · Recherche · Favoris · Commandes · Profil

**Pages (former modals):** Product, Store, Reserve, IA scan, Add part (seller)

**Header:** Acheteur / Magasin, city, IA Mécano

## Demo data

17 products, 5 shops, vehicle types (scooter / moto / mobylette / car), categories + sub-categories, sample orders `RES-2026-081` and `RES-2026-094`.
